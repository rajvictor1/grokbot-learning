## What this is

A step-by-step learning guide covering:
- The right tool mindset (GrokBot vs Claude/Codex/ChatGPT Work)
- GrokBot architecture: cloud computer, shared memory, shared screens
- The 4-C design rule: Context → Connections → Capabilities → Cadence
- Building a Chief of Staff bot
- Designing specialist scouts by task, not by tool
- Live examples: X Research Scout, Newsletter Scout, Job Scraper, Analogy Builder
- Bots talking to each other in group chats and stand-ups
- Skills, plugins, security, usage/billing, and coding agents

## Tech stack

- Next.js 14 (static export)
- React + TypeScript
- Tailwind CSS
- Lucide icons

## Run locally

```bash
npm install
npm run build
# Open dist/index.html or run:
npm run dev
```
